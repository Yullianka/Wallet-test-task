# Wallet App - React Test Task

A mobile-first wallet application built with React, TypeScript, and Vite. This project is a test task demonstrating modern frontend development practices, UI/UX implementation from a design reference, and functional transaction logic.

## Features

- **Transaction Dashboard**: Displays the user's current balance, calculated daily points, and a list of recent transactions.
- **Transaction Details**: Dynamic routing to view the detailed breakdown of a specific transaction.
- **Points Algorithm**: Dynamic calculation of daily points based on the current season's progression.
- **Custom Styling**: High-fidelity UI matching the provided design reference using strict CSS Modules (zero inline styles).
- **Smart Formatting**: Localized date representations and concise number formatting.

## Technologies Used

- React
- TypeScript
- Vite
- React Router DOM
- CSS Modules
- FontAwesome Icons

## Getting Started

### Prerequisites
- Node.js
- pnpm (or npm/yarn)

### Installation & Running

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start the development server:
   ```bash
   pnpm run dev
   ```
